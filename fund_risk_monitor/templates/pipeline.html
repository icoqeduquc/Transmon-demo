🌲 What is XGBoost?

XGBoost (eXtreme Gradient Boosting) is an ensemble learning algorithm. It trains multiple decision trees sequentially, each correcting the errors of the previous ones.

This system uses 200 decision trees, each up to 6 levels deep, evaluated across 80+ feature dimensions.

Final Score = Tree₁ + Tree₂ + Tree₃ + ... + Tree₂₀₀

Each tree contributes an independent score. The sum is passed through a Sigmoid function to produce a 0–100% risk probability.

🔀 How does a decision tree decide?

Each tree starts at the root and performs binary splits based on feature values, following a path to a leaf node:

Amount > 1M? → Yes → High-risk region? → Yes → Score +0.8
Amount > 1M? → No → Account > 1yr? → Yes → Score -0.3

Different trees focus on different feature combinations, complementing each other for accurate ensemble predictions.

📊 Model Training

The model is trained on historical transaction data with manually labeled risk outcomes:

  • Training data: 10,000+ transactions (90% normal + 10% risky)
  • Feature engineering: 80 dimensions from 50+ raw fields (incl. derived features)
  • Training method: Gradient boosting — each round adds a tree to fix residuals
  • Evaluation: AUC-ROC > 0.95, Accuracy > 92%
  • Update frequency: Recommended weekly/monthly with latest data

⚡ Real-time Inference Pipeline

Full processing flow for each incoming transaction:

① TX Input → ② Feature Extraction → ③ Model Inference → ④ Rule Matching → ⑤ Final Verdict

Model inference: XGBoost 200 trees in parallel, <1ms, outputs risk probability

Rule matching: 9 categories / 43 deterministic rules checked, outputs hit details

Final verdict: Probability ≥ 60% triggers alert, enters manual review queue

💡 ML model excels at detecting hidden patterns (e.g. feature combination anomalies); rule engine handles hard compliance checks (e.g. blacklists, amount thresholds). Together they form a complete risk control system.
